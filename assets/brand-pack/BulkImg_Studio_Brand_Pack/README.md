## Official direction

- Design system: SlateStack Design System (SSDS)
- System type: Fully custom
- Primary palette: Deep slate to cool gray
- Display typeface: Manrope
- Interface typeface: Inter
- Technical typeface: JetBrains Mono
- Implementation foundation: Radix UI + Tailwind CSS + CSS variables
- Primary logo: Dark-mode slate logo
- Secondary logo: Light slate-gray logo

The provided logo PNG files are raster assets. Preserve their proportions and do not redraw or recolor them without updating the brand specification.
