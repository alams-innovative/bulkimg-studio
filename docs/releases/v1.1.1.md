# BulkImg Studio v1.1.1 — Stable

## Highlights

- A simpler Generator flow: add prompts, choose output, then generate. Reference images and Batch planning stay available when needed without crowding the first screen.
- Generate is protected against repeated clicks for ten seconds after launch, and a clear confirmation shows when the sequence has started.
- Stable update delivery, verified downloads, diagnostics, USD/PKR display, and laptop layout refinements are included from the 1.1 beta cycle.

## What changed

### Improved

- Format and quality stay visible as the essential output choices.
- Reference images and custom Batch plans use compact expandable sections.
- Destructive prompt actions are grouped under a compact More menu.
- Logs can create a copyable support report and a sanitized diagnostics ZIP.

### Fixed

- Repeated Generate clicks cannot create duplicate submissions while the launch guard is active.
- The app confirms a Direct or Batch sequence immediately after it has been accepted, including guided batches whose first wave completes quickly.
- Generator layouts have been verified at desktop and common laptop resolutions.

## Upgrade notes

- This update preserves local API keys, prompt drafts, history, saved images, exports, and usage data.
- Stable builds use the Stable update channel. You can opt into beta updates later from **About & updates**.

## Download

1. Download `BulkImgStudio-Setup.zip`.
2. Extract the whole ZIP.
3. Run `Install-BulkImgStudio.cmd`.

Do not run the setup executable by itself—the adjacent `.installer` folder is required.
