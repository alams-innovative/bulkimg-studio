# BulkImg Studio v1.1.0-beta.7 — Beta

> Beta release: this contains newer changes that may disrupt your workflow. Stable is recommended for normal production use.

## Highlights

- Checks for signed releases at startup and every 15 minutes using lightweight ETag polling.
- Automatically downloads and verifies a newer signed release in the background, then shows a ready notification and a green indicator beside **About**.
- Keeps installation explicit. **Install and restart** opens a clear in-app confirmation; selecting a version only selects it and never starts a download.
- Adds durable UI diagnostics for navigation, updater actions, surfaced errors, and uncaught UI failures. Existing generator, converter, history, export, and service errors continue to be written to the same local Diagnostics log.

## Update test

From v1.1.0-beta.6, open **About** and enable **Receive beta updates**. Within 15 minutes (or after **Check for updates**), v1.1.0-beta.7 downloads and verifies in the background. A toast and green About indicator mean it is ready; choose **Install and restart** only when you are ready to close the app.
