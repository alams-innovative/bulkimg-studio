# BulkImg Studio v1.1.0 — Stable

## Highlights

- Stable Windows release with signed updates, automatic verified download, and explicit install confirmation.
- Startup now applies the native dark window treatment and fully syncs the WebView before it appears, avoiding the resize-only layout defect.
- Clear USD/PKR selection, compact Usage controls, and fixed inline scrolling for Version history and Library.

## What changed

### Improved

- A beta build selects the Beta update channel on its first launch; Stable builds select Stable while respecting later user choices.
- Library image previews are smaller, remain inside the inline scroller, and no longer shift on hover.
- Version history and Library keep their headers and controls visible while their long lists scroll independently.

### Fixed

- Dark-first startup now waits for a stable UI layout and resyncs the native WebView frame before reveal.
- The currency selector now clearly marks whether USD or PKR is active.

## Upgrade notes

- This update preserves local API keys, history, saved images, and usage data.
- The update ZIP is verified using the signed manifest, exact byte-size check, and SHA-256 checksum.

## Download

1. Download `BulkImgStudio-Setup.zip`.
2. Extract the whole ZIP.
3. Run `Install-BulkImgStudio.cmd`.

Do not run the setup executable by itself—the adjacent `.installer` folder is required.
