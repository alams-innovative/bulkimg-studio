# BulkImg Studio v1.0.8 — Stable

## Highlights

- Cleaner automatic cost estimates for Direct and Batch image runs.
- More reliable Windows startup sizing.
- Clearer update controls and Alams Innovate product ownership.

## What changed

### Improved

- The app opens at a safe work-area-bounded size without the first-paint maximize race.
- The Generator estimate now states the image count, reference-image count, and Direct or Batch rate it is using.
- The Usage page keeps actual usage, costs, history, and limits while presenting image and reference estimates in plain language.
- Batch prices are shown as the final Batch amount, rather than requiring discount math.

### Fixed

- Download and install buttons are hidden when there is no compatible update to install.

### Legal

- BulkImg Studio is now distributed under an All Rights Reserved proprietary license.

## Upgrade notes

- This update preserves your local API keys, history, and saved images.
- Open **About & updates** and choose **Check for updates** to download the verified release.
