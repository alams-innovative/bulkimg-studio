# BulkImg Studio v1.0.7 — Stable

## Highlights

- Added secure in-app updates with Stable and opt-in Beta channels.
- Improved batch generation recovery and guided wave controls.
- Refined the image library and desktop launch experience.

## What changed

### Added

- Signed update manifests and SHA-256 installer verification.
- An About & updates screen with version history, update checks, downloads, and explicit install confirmation.
- Stable/Beta update-channel selection and Beta recovery support.
- Release automation for building, signing, and publishing update assets.

### Improved

- Recovery for interrupted image-generation sessions.
- Guided batch-wave planning.
- Library browsing, clipboard workflow, and desktop launch behavior.
- Automated desktop and laptop UI coverage.

### Fixed

- Guided-wave handoff behavior between batches.
- Upgrade handling for existing local installations.

## Upgrade notes

- This release updates your existing BulkImg Studio installation.
- Your local API keys, history, and saved images remain on this device.
- The first updater-enabled build must be installed manually. Later compatible releases can be installed from **About & updates**.

## Download

1. Download `BulkImgStudio-Setup.zip`.
2. Extract the entire ZIP.
3. Run `Install-BulkImgStudio.cmd`.

Do not run the setup executable by itself—the adjacent `.installer` folder is required.

## Verification

The release includes a signed `bulkimg-update.json` manifest containing the installer SHA-256 checksum.
