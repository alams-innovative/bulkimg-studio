# BulkImg Studio v1.1.0-beta.2 — Beta

> Beta release: this contains newer changes that may disrupt your workflow. Stable is recommended for normal production use.

## Highlights

- Makes the verified update handoff run `Install-BulkImgStudio.cmd` reliably and confirms the installed version before launch.
- Shows PKR automatically using the State Bank of Pakistan rate, with the USD amount shown alongside it.
- Simplifies reference-image input to browse or drag and drop; clipboard shortcuts are no longer attached to that control.
- Lets Converter queue up to 1,000 images and processes them in PC-aware batches with bounded local workers.

## Download

1. Download `BulkImgStudio-Setup.zip`.
2. Extract the whole ZIP.
3. Run `Install-BulkImgStudio.cmd`.

The `.installer` folder must remain beside the setup executable.
