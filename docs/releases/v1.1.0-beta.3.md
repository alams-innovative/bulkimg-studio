# BulkImg Studio v1.1.0-beta.3 — Beta

> Beta release: this contains newer changes that may disrupt your workflow. Stable is recommended for normal production use.

## Highlights

- Repairs the automatic update helper so it waits for the installer to finish without waiting on the newly restarted app process.
- Keeps update-error toasts inside compact laptop windows and above the pinned Generate controls.
- Uses a more compact generator layout on shorter laptop displays, reducing unnecessary page scrolling.

## Update test

From v1.1.0-beta.2, open **About**, keep **Receive beta updates** enabled, then choose **Check for updates** and **Download and install** for v1.1.0-beta.3. The app should close, install, restart, and show v1.1.0-beta.3 in About.
