# BulkImg Studio v1.0.9 — Stable

## Fixed

- The verified update download now waits for the file to finish writing before it checks the signed size and checksum.
- The Windows installer helper now runs independently of the app that is closing and confirms it has started before the app exits.
- If an installer helper later fails, the next app launch explains the failure in **About & updates** and preserves the current working app.

## Upgrade notes

- This update preserves local API keys, history, and saved images.
- The update ZIP remains protected by its signed manifest, exact byte-size check, and SHA-256 checksum.
