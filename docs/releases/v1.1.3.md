# BulkImg Studio v1.1.3 — Stable

## Highlights

- Downloading exactly one selected image now saves that original image file directly instead of wrapping it in a ZIP.
- Multi-image exports remain ZIP archives, so batch downloads continue to stay organized.

## What changed

### Added

- Single-image export detects the original image type and keeps its file extension.

### Improved

- Export labels now describe whether the result is an image download or a ZIP archive.
- Visual release checks accommodate small Windows font-rasterization differences while retaining explicit layout-boundary assertions.

### Fixed

- Cancelling the image save dialog leaves the export untouched.
- The export manifest continues to report missing source files without failing a multi-image archive.

## Upgrade notes

- This update preserves local API keys, prompt drafts, history, saved images, exports, and usage data.
- Existing ZIP exports remain available in the Exports view.

## Download

1. Download `BulkImgStudio-Setup.zip`.
2. Extract the whole ZIP.
3. Run `Install-BulkImgStudio.cmd`.

Do not run the setup executable by itself—the adjacent `.installer` folder is required.

## Verification

The signed `bulkimg-update.json` included with the release contains the installer SHA-256 checksum.
