# BulkImg Studio v1.1.0-beta.6 — Beta

> Beta release: this contains newer changes that may disrupt your workflow. Stable is recommended for normal production use.

## Highlights

- Automatically checks signed GitHub releases once at startup and then every 15 minutes while the app is open.
- Keeps normal update polling lightweight with GitHub ETag caching: unchanged polls do not download installers, manifests, signatures, or release history again.
- Keeps installation explicit: finding an update never downloads or installs it without your confirmation.

## Update test

From v1.1.0-beta.5, open **About**, enable **Receive beta updates**, then choose **Check for updates** or wait up to 15 minutes. v1.1.0-beta.6 should appear as available; download and install remain manual confirmation steps.
