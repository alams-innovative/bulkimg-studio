# BulkImg Studio v1.1.1-beta.0 — Beta

## Batch clarity and support diagnostics

- Uses **Batch 1**, **Batch 2**, and **Batch plan** consistently in Generator, Sessions, and Library. Existing runs and saved work remain compatible.
- Adds a paste-ready **Copy support report** action in Logs, including the running app version and the selected sanitized diagnostic events.
- Adds **Download diagnostics**, which creates a sanitized ZIP with a human-readable support report and diagnostic JSONL for troubleshooting.
- Centralizes the running app version and validates package, brand, installer, release tag, and manifest version alignment before a release build.

## Beta note

This is a prerelease. Enable **Receive beta updates** in About & updates to receive it. Installer downloads are verified; installation remains confirmation-gated unless idle installation was explicitly enabled.
